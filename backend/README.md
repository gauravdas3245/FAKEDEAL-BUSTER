# Backend

This directory contains the backend application and REST API for FakeDeal Buster.

## Planned Technology

- Python
- FastAPI
- Uvicorn
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Planned Responsibilities

- Receive product information from the frontend.
- Validate incoming requests.
- Process product pricing data.
- Load the trained machine learning model.
- Generate discount analysis results.
- Return structured responses to the frontend.

## Planned API

- `GET /` — API health check.
- `GET /health` — Backend health status.
- `POST /analyze` — Analyze submitted product information.

## Development Status

Initial setup pending. API implementation and request/response schemas will be finalized during development.
