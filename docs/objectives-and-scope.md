
# Project Objectives and Scope

## 1. Project Objectives

The primary objective of FakeDeal Buster is to develop a machine learning-based application that analyses e-commerce product pricing information and identifies potentially misleading artificial discounts.

### Specific Objectives

1. Analyse product prices and discount percentages.
2. Examine the relationship between original price and current selling price.
3. Identify pricing patterns that may indicate artificial discounts.
4. Prepare and process the selected e-commerce dataset.
5. Develop and evaluate machine learning models for discount classification, subject to label validity.
6. Provide clear analysis results through a user-friendly web interface.
7. Examine historical price trends where sufficient data is available.
8. Test the application for functionality, reliability, and usability.

## 2. Project Scope

### Included in Scope

- Analysis of the approved e-commerce product price dataset.
- Data cleaning and preprocessing.
- Exploratory data analysis and feature engineering.
- Machine learning model development and evaluation.
- Manual entry of product pricing information.
- Backend API development using Python and FastAPI.
- Frontend development using React.js.
- Display of analysis results through the web interface.
- Historical price analysis where sufficient records are available.
- Local deployment and testing.

### Excluded from Initial Scope

- Guaranteed detection of actual marketplace fraud.
- Automatic live scraping of every e-commerce platform.
- Real-time integration with commercial shopping websites.
- Online payment or purchasing functionality.
- Browser extensions or mobile applications.
- Commercial-scale cloud deployment.

## 3. Target Users

- Online shoppers who want to evaluate advertised discounts.
- Students and researchers interested in e-commerce price analysis.
- Users who want to understand product pricing patterns.

## 4. Project Deliverables

1. Prepared and documented dataset workflow.
2. Trained and evaluated machine learning model, if supported by valid labels.
3. FastAPI backend.
4. React.js frontend.
5. Integrated FakeDeal Buster web application.
6. Testing results and project documentation.
7. Final academic project presentation.

## 5. Scope Limitations

The accuracy and reliability of the system depend on the quality and validity of the selected dataset, available features, and model evaluation.

Predictions will be presented as analytical assessments rather than definitive proof that a seller or platform has committed fraud.
