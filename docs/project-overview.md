
# FakeDeal Buster — Project Overview

## Project Information

- **Project Name:** FakeDeal Buster
- **Institution:** Scholar Institute of Technology and Management (SITM), Guwahati

- **Group:** B
- **Faculty Mentor:** Mr. Nitish Kr. Sarma
- **Project Type:** Machine Learning-Based Web Application

## Introduction

FakeDeal Buster is a machine learning-based e-commerce discount analysis system designed to identify potentially misleading artificial discounts.

During online sale events, products may display large discount percentages that do not necessarily represent genuine price reductions. This project aims to analyse available product pricing information and help users understand whether a displayed discount appears reasonable or potentially misleading.

## Problem Statement

Customers often find it difficult to determine whether an advertised discount represents a genuine price reduction. A high discount percentage alone does not establish that a product is being offered at a genuine bargain.

FakeDeal Buster addresses this problem through data analysis, machine learning-based classification, and price trend examination where sufficient historical data is available.

## Proposed Solution

The application will accept product-related information and analyse relevant pricing features. Based on the implemented analysis, it will provide an understandable result indicating whether the discount appears genuine or potentially misleading.

## Main Objectives

1. Analyse product pricing information.
2. Examine relationships between original price, current price, and discount percentage.
3. Identify potentially artificial or misleading discounts.
4. Apply machine learning techniques to support discount classification.
5. Present analysis results through a simple web interface.
6. Explore historical price trends where sufficient data is available.

## Expected Outcome

A locally deployable web application that demonstrates discount analysis using the selected dataset and machine learning techniques.

The system is an academic prototype. Its results should not be interpreted as proof of fraud or as a guarantee of actual marketplace pricing accuracy.

## Project Scope

The initial version focuses on product price analysis using the approved dataset and manually supplied product information.

Live marketplace scraping, commercial deployment, and guaranteed real-world fraud detection are outside the confirmed initial scope.
