# Machine Learning

This directory contains the data analysis and machine learning components of FakeDeal Buster.

## Planned Technology

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Matplotlib

## Planned Responsibilities

- Dataset inspection and validation
- Data cleaning and preprocessing
- Feature engineering
- Price and discount analysis
- Model training and evaluation
- Model serialization and loading

## Planned Algorithms

- Logistic Regression
- Random Forest Classifier
- Anomaly detection using a suitable statistical or machine learning method

## Important Validation Rule

The dataset labels must be inspected and verified before supervised model training. No model accuracy or fraud-detection performance will be claimed without proper evaluation.
