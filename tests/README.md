# Tests

This directory contains test cases and testing resources for FakeDeal Buster.

## Testing Areas

- Backend API testing
- Input validation testing
- Machine learning model testing
- Frontend and backend integration testing
- End-to-end application testing

## Testing Guidelines

- Test valid and invalid inputs.
- Verify API response structures.
- Check model output consistency.
- Record failed test cases and their fixes.
- Do not report tests as passed until they have actually been executed.
